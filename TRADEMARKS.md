# Ember CoreUI Branding and Trademark Policy

## Protected project identity

The following names and visual elements identify the Starlight Unit Studios project:

- `STΛRLIɢHT: Ember CoreUI`
- `Ember CoreUI`
- `Starlight Unit Studios`
- the Starlight Unit Studios logo and word marks
- the original Ember CoreUI interface marks and studio attribution elements

No trademark registration is asserted by this file unless separately documented. Copyright, naming, unfair-competition, and other applicable rights remain reserved.

## Mandatory name format

The product must always be called **Ember CoreUI**. For prominent first references, the preferred complete form is:

`STΛRLIɢHT: Ember CoreUI by Starlight Unit Studios`

The standalone product name `CoreUI` must not be used for this project. It does not identify Ember CoreUI and creates avoidable confusion with an unrelated software project.

## Required presentation

Built-in names, logos, copyright notices, About information, login branding, splash branding, and source attribution must remain visible and must not be removed, replaced, covered, recolored, or reduced to a misleadingly minor role.

An operator may add a clearly subordinate notice such as `Hosted by Example Organization`. The operator notice must not replace Ember CoreUI branding or imply that the operator is Starlight Unit Studios.

Public modifications must state:

`This is an unofficial modification of Ember CoreUI and is not maintained or officially supported by Starlight Unit Studios.`

## Technical identifiers

Compatibility identifiers such as `coreui`, `ember-coreui`, `COREUI_*`, `/opt/ember-coreui`, `X-CoreUI-CSRF`, database prefixes, repository slugs, and domain components may remain unchanged. They are machine-facing identifiers, not permitted standalone product branding.

## Independence statement

Ember CoreUI is independently developed by Starlight Unit Studios. The source tree contains no dependency on the unrelated admin-template and UI-component project available at `coreui.io`. Ember CoreUI is not affiliated with, sponsored by, or endorsed by that project.

Any branding change outside the terms of the Ember CoreUI Community Source License requires prior express written permission from the rights holder. Permission for one deployment does not create a general permission for another deployment.
